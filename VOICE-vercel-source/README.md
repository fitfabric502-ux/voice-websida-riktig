# VOICE

A responsive React + Tailwind concept for VOICE, built from the supplied project brief. Reference screenshots informed the atmosphere and composition; the original files are untouched.

## Run

- `npm install`
- `npm run dev`
- `npm run build`

## Prototype scope

Signals and analysis are illustrative. Checkout adds demo credits to the current session without payments. The waitlist stores interest only in this browser, and does not submit email addresses. No microphone or external AI service is used. Launch dates and a Discord URL have not been supplied.

## Media

`public/media` is reserved for production media. The current experience uses CSS/SVG signal rings and waveforms so it does not depend on missing video files. Future video backgrounds can use `voice-hero-loop.mp4`, `voice-nodes-loop.mp4`, `voice-species-preview.mp4`, and `voice-poster.webp`. Use muted, loop, playsInline and a poster; disable autoplay when reduced motion is requested.

## Integration points

Replace the simulated checkout, local waitlist submission, and synthetic signal data with verified services when available. Species profiles avoid precise measured frequency claims because the demo does not contain measured recordings.
